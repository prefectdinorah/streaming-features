# Форма добавления видео в UI

## Что добавлено

✅ **Форма добавления видео** прямо из Dashboard
✅ **Автосохранение имени** в localStorage (не нужно вводить каждый раз)
✅ **Валидация YouTube ссылок** (поддержка всех форматов)
✅ **Уведомления об успехе/ошибках**

## Где находится

Откройте **Dashboard → Очередь**: http://localhost:3000/dashboard/queue

Форма расположена **между перемоткой и текущей очередью**.

## Как использовать

### Шаг 1: Введите YouTube URL

Поддерживаемые форматы:
- `https://www.youtube.com/watch?v=dQw4w9WgXcQ`
- `https://youtu.be/dQw4w9WgXcQ`
- `https://m.youtube.com/watch?v=dQw4w9WgXcQ`

### Шаг 2: Введите имя

Ваше имя или никнейм (будет показано в очереди)

**Совет:** После первого добавления имя сохранится автоматически!

### Шаг 3: Нажмите "Добавить в очередь"

Видео будет:
- ✅ Проверено на валидность
- ✅ Загружены метаданные с YouTube
- ✅ Проверено на дубликаты (если настроено)
- ✅ Проверено на длительность (если настроено)
- ✅ Добавлено в конец очереди

### Шаг 4: Автоматическое обновление

Страница автоматически обновится и вы увидите новое видео в очереди.

## Возможные ошибки

### ❌ "Неверная YouTube ссылка"

**Причина:** Ссылка не содержит video ID

**Решение:** Проверьте формат ссылки (см. поддерживаемые форматы выше)

### ❌ "Видео слишком длинное"

**Причина:** Превышена максимальная длительность

**Решение:** Выберите более короткое видео или измените настройки в Dashboard → Настройки

### ❌ "Это видео уже в очереди"

**Причина:** Дубликаты запрещены в настройках

**Решение:** Дождитесь воспроизведения текущего или разрешите дубликаты в настройках

### ❌ "Очередь переполнена"

**Причина:** Достигнут максимальный размер очереди

**Решение:** Дождитесь воспроизведения видео или увеличьте `max_queue_size` в настройках

### ❌ "Не удалось загрузить видео"

**Причина:**
- Видео удалено или приватное
- YouTube API вернул ошибку
- Нет YouTube API ключа в env

**Решение:**
1. Проверьте что видео существует и публичное
2. Проверьте `YOUTUBE_API_KEY` в `.env.local`

## Технические детали

### API Endpoint

Форма использует `POST /api/queue/add`:

```typescript
{
  youtubeUrl: string,  // YouTube URL
  requestedBy: string  // Имя пользователя
}
```

### Валидация

Выполняется на уровне API:
- ✅ Проверка формата URL (Zod)
- ✅ Извлечение video ID
- ✅ Загрузка метаданных с YouTube API
- ✅ Проверка длительности (если настроено)
- ✅ Проверка дубликатов (если настроено)
- ✅ Проверка размера очереди

### Автосохранение имени

Имя сохраняется в `localStorage` под ключом `requestedBy`:

```javascript
// При успешном добавлении
localStorage.setItem('requestedBy', requestedBy)

// При загрузке формы
const savedName = localStorage.getItem('requestedBy')
```

### Обновление UI

После успешного добавления:
1. ✅ Показывается зеленое уведомление "Видео добавлено"
2. ✅ URL очищается
3. ✅ Имя сохраняется
4. ✅ Страница автоматически обновляется (через 3 секунды)
5. ✅ Новое видео появляется в очереди

## Кастомизация

### Изменить максимальную длительность видео

```sql
UPDATE twitch_player.player_settings
SET max_video_duration = 900; -- 15 минут
```

### Разрешить дубликаты

```sql
UPDATE twitch_player.player_settings
SET allow_duplicates = true;
```

### Изменить размер очереди

```sql
UPDATE twitch_player.player_settings
SET max_queue_size = 100;
```

## Альтернативные способы добавления

Кроме UI формы, видео можно добавить:

### 1. Через Twitch бота

```
!play https://www.youtube.com/watch?v=dQw4w9WgXcQ
```

### 2. Через API напрямую (curl)

```bash
curl -X POST http://localhost:3000/api/queue/add \
  -H "Content-Type: application/json" \
  -d '{
    "youtubeUrl": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
    "requestedBy": "YourName"
  }'
```

### 3. Через Postman/Insomnia

POST `http://localhost:3000/api/queue/add`

Body (JSON):
```json
{
  "youtubeUrl": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
  "requestedBy": "YourName"
}
```
