### ✅ 2. Сохранение позиции при переоткрытии вкладки

**Проблема:** При открытии новой вкладки `/player` видео начиналось заново

**Решение:**
- Добавлено поле `current_position` в `player_settings`
- Плеер сохраняет текущую позицию каждые 5 секунд в БД
- При создании плеера восстанавливается сохраненная позиция
- При переключении на новое видео позиция сбрасывается в 0

**Как работает:**
1. Видео играет → каждые 5 секунд сохраняется позиция
2. Закрыл вкладку → позиция сохранена в БД
3. Открыл новую вкладку → видео продолжается с того же места

### ✅ 3. Прозрачный фон для OBS

**Проблема:** Когда очередь пуста - черный квадрат в OBS

**Решение:**
- Убран черный фон (`bg-black` → `background: transparent`)
- Когда нет видео - пустой прозрачный контейнер
- В OBS Browser Source будет прозрачным

**Настройка в OBS:**
1. Выберите Browser Source с плеером
2. Properties → Custom CSS (если нужно):
   ```css
   body { background-color: rgba(0,0,0,0); }
   ```
3. Теперь когда очередь пуста - источник прозрачен, видно что под ним

## Известные ограничения

### Сохранение позиции

- Позиция сохраняется каждые **5 секунд**
- При резком закрытии вкладки может потеряться до 5 секунд прогресса
- Это нормально и не критично

### Прозрачность в OBS

- YouTube IFrame сам по себе имеет черный фон
- Прозрачность работает только когда **нет видео**
- Когда видео играет - будет виден YouTube Player

## Если что-то не работает

### Позиция не сохраняется

Проверьте логи в консоли `/player`:
```
[YouTubePlayer] Saved position: ???
```

Если логов нет → проверьте что миграция применена:
```sql
SELECT column_name FROM information_schema.columns
WHERE table_schema = 'twitch_player'
AND table_name = 'player_settings';
```

Должно быть `current_position` в списке.

### Фон не прозрачный в OBS

1. Убедитесь что очередь **действительно пуста** (нет pending видео)
2. В OBS → Browser Source → Properties → проверьте что **нет** кастомного background в CSS
3. Если нужно - добавьте в Custom CSS:
   ```css
   body { background-color: rgba(0,0,0,0) !important; }
   ```
